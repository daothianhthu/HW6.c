# 과제 06 - 순차 탐색, 이진 탐색 트리와 AVL 트리의 성능 비교

## 1. 실험 개요

본 프로그램에서는 0부터 1,000 사이의 정수 100개를 임의로 생성하고,
생성된 데이터를 정수 배열(Array), 이진 탐색 트리(BST), AVL 트리에 저장하였다.

중복된 값이 생성된 경우에는 해당 값을 다시 저장하지 않고,
각 자료구조에 저장되는 값은 서로 중복되지 않도록 하였다.

이후 50개의 검색 키를 생성하고,
동일한 검색 키를 Array, BST, AVL 트리에서 각각 검색하여
각 자료구조의 비교 횟수를 측정하였다.

## 2. 데이터 생성 및 저장 결과

이번 실행에서는 총 100개의 정수가 생성되었다.

서로 다른 값: 97개
중복된 값: 3개
Array에 저장된 값: 97개
구조별 생성 및 저장 과정에서의 비교 횟수는 다음과 같다.

자료구조: 비교 횟수
Array :4753
BST :577
AVL :541

## 3. 트리 높이 비교

생성된 데이터를 저장한 후 BST와 AVL 트리의 높이를 측정하였다.
트리 : 높이
BST : 12
AVL : 8

## 3. 트리 높이 비교

BST의 높이는 13, AVL 트리의 높이는 8이었다.
BST는 균형을 유지하지 않으므로 난수가 입력된 순서에 따라 한쪽으로
치우친 구조가 만들어졌고, 그 결과 높이가 13까지 커졌다.
AVL 트리는 삽입 후 LL, RR, LR, RL 회전으로 모든 노드의 좌우 서브트리
높이 차이를 1 이하로 유지하므로 높이가 8로 유지되었다.
저장된 값이 93개이므로 이론적 최소 높이는 7이며, AVL의 8은 이에 매우 가깝다.

## 4. 검색 결과

50개의 검색 키를 동일하게 Array, BST, AVL 트리에서 검색하였다.검색 결과의 총 비교 횟수와 평균 비교 횟수는 다음과 같다.

Array total = 4677
Array avg = 93.54

BST total = 371
BST avg = 7.42

AVL total = 334
AVL avg = 6.68

## 5. 결과 분석

Array의 평균 비교 횟수는 93.54회로 BST와 AVL 트리보다 훨씬 높게 나타났다.

Array에서는 정렬을 하지 않고 순차 탐색을 사용하기 때문에
검색할 값을 찾기 위해 배열의 처음부터 하나씩 비교해야 한다.
특히 검색에 실패한 경우에는 저장된 모든 원소를 확인해야 하므로
비교 횟수가 많아진다.

BST의 평균 비교 횟수는 7.42회로 Array보다 크게 감소하였다.
BST에서는 현재 노드의 값과 검색 값을 비교한 후
작으면 왼쪽, 크면 오른쪽으로 이동하기 때문에
검색하지 않아도 되는 부분을 제외할 수 있다.

AVL 트리의 평균 비교 횟수는 6.68회로 세 자료구조 중 가장 낮았다.
AVL 트리는 삽입 과정에서 회전을 수행하여 트리의 균형을 유지하기 때문에 BST보다 높이가 낮게 유지되었다.

한 번의 검색에서 비교 횟수는 트리의 높이를 넘을 수 없다.
BST에서는 키 450과 460의 검색에 13회가 필요했지만 AVL에서는 7회였다.
반대로 키 757과 759는 BST에서 3회로 AVL(7회)보다 적었는데,
이는 해당 키가 BST의 얕은 가지에 위치했기 때문이다.
따라서 AVL이 모든 검색에서 유리한 것은 아니며,
최악의 경우(13 대 8)와 평균(7.60 대 6.66)에서 유리하다.
Array의 평균 90.56회는 AVL(6.66회)의 약 13.6배이다.

## 6. 생성 비용과 검색 성능의 비교

BST와 AVL 트리는 데이터를 저장할 때 Array보다 적은 비교 횟수를 사용하였다.
이번 실험에서 생성 및 저장 과정의 비교 횟수는 Array가 4753회,
BST가 577회, AVL이 541회였다.

검색 과정에서도 BST와 AVL이 Array보다 훨씬 적은 비교 횟수를 보였다.

특히 AVL 트리는 삽입 과정에서 회전과 높이 계산 등의 추가 작업이 필요하지만,
균형을 유지하기 때문에 검색 성능이 좋다는 장점이 있다.

따라서 많은 데이터를 저장한 후 검색을 자주 수행하는 경우에는
AVL 트리와 같은 균형 이진 탐색 트리가 효과적이라고 생각할 수 있다.

## 7. 결론

이번 실험을 통해 Array, BST, AVL 트리의 검색 성능을 비교하였다.

Array는 구현이 간단하지만 순차 탐색을 사용하기 때문에
검색에 필요한 비교 횟수가 많았다.

BST는 트리의 구조를 이용하여 Array보다 적은 비교 횟수로 검색할 수 있었다.
AVL 트리는 BST보다 트리의 균형을 잘 유지하여
이번 실험에서 가장 낮은 평균 검색 비교 횟수를 보였다.

이번 실험 결과는 다음과 같다.

Array 평균 검색 비교 횟수: 93.54
BST 평균 검색 비교 횟수: 7.42
AVL 평균 검색 비교 횟수: 6.68

따라서 이번 실험에서는 AVL 트리가 세 자료구조 중 가장 효율적인
검색 성능을 보여주었다.
